# 🧩 Scirpus - App de Acertijos y Desafíos Mentales

[![Kotlin](https://img.shields.io/badge/Kotlin-7F52FF?style=flat&logo=kotlin&logoColor=white)](https://kotlinlang.org/)
[![Android](https://img.shields.io/badge/Android-3DDC84?style=flat&logo=android&logoColor=white)](https://developer.android.com/)
[![Status](https://img.shields.io/badge/Status-Completed-brightgreen)](#)

Aplicación móvil nativa para Android enfocada en la resolución de acertijos, adivinanzas y retos de lógica. La aplicación organiza el contenido en distintas temáticas y niveles de dificultad, desde acertijos sencillos y matemáticos hasta desafíos complejos.

---

### 🚀 Características Principales

- 📚 **Categorización por Temáticas:** Acertijos clasificados por lógica, matemáticas, acertijos cortos y pensamiento lateral.
- 📈 **Niveles de Dificultad Gradual:** Filtrado desde retos sencillos hasta niveles muy difíciles.
- 💡 **Sistema de Pistas y Soluciones:** Gestión de estados para revelar pistas progresivas o comprobar las respuestas.
- 🏆 **Control de Progreso:** Seguimiento local de acertijos completados y estadísticas del usuario.

---

### 🛠️ Tecnologías Utilizadas

- **Lenguaje:** Kotlin
- **Plataforma:** Android SDK
- **Interfaz de Usuario:** XML Layouts / RecyclerViews para filtrado de categorías
- **Persistencia Local:** SharedPreferences / DataStore para guardar el avance
- **IDE:** Android Studio
